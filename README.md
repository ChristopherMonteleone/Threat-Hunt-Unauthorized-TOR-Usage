# Threat Hunt Scenario: Unauthorized TOR Usage
A threat hunting case study documenting the detection of unauthorized TOR browser installation and network activity using Microsoft Defender for Endpoint and Kusto Query Language (KQL)

## Technical Stack
**Microsoft Azure** (Hosted Windows 10 Virtual Machines to establish a controlled lab environment).

**Microsoft Defender for Endpoint** (Deployed EDR platform for real-time monitoring, telemetry generation, and incident response).

**Kusto Query Language (KQL)** (Constructed complex queries for advanced log analysis and threat hunting).

**Tor Browser** (Generated anonymized network traffic to test detection capabilities).
